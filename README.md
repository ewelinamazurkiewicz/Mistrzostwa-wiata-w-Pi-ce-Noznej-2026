## 📌 Project Overview

This project presents an interactive dashboard analyzing the FIFA World Cup 2026 tournament. The goal was to transform raw football data into meaningful business insights by building a complete analytical solution using Python and Power BI.

The project covers the entire analytics workflow:

- Data collection
- Data cleaning and transformation in Python
- Data modeling in Power BI
- DAX measures and KPIs
- Interactive dashboard creation
- Business storytelling

# 📚 Data Preparation

Data preprocessing was performed in Python using Pandas.

Main steps included:

- Removing duplicates
- Handling missing values
- Standardizing country names
- Data type conversion
- Feature engineering
- Creating calculated statistics
- Exporting clean CSV files for Power BI

# ⭐ Key Insights

Examples of insights generated by the dashboard:

- Which team scored the most goals?
- In which part of match (minutes) teams score the most goals?
- Which stadium hosted the most matches?
- Which players contributed the most goals?
- Which age group scores the most goals?

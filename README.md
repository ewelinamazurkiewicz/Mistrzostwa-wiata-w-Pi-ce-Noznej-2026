# ⚽ FIFA World Cup 2026 Dashboard | Power BI & Python

## 📌 Project Overview

This project presents an interactive dashboard analyzing the FIFA World Cup 2026 tournament. The goal was to transform raw football data into meaningful business insights by building a complete analytical solution using Python and Power BI.

The project covers the entire analytics workflow:

- Data collection
- Data cleaning and transformation in Python
- Data modeling in Power BI
- DAX measures and KPIs
- Interactive dashboard creation
- Business storytelling
